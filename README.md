# Team 12 Project 3

This project is a web-based frontend for Panda Express that supports manager 
reports and a kiosk-style ordering system for customers.

## Novel Feature

We aim to build a machine learning model that can predict when the manager 
needs to restock ingredients based on the current inventory and sales data.
The model is a recurrent neural netowrk  and will be trained on the historical 
sales data of 1 year automatically generated by the Python script utilized in 
Project 2.

The recurrent neural network will ingest the ingredient type, quantity, and 
date as features and will output a prediction of the ingredient quantity at the
end of the next day.

The reason this feature is being developed is because in the real world, orders
take time to place and arrive, and incorrectly-determined restock thresholds 
can lead to either overstocking or understocking of ingredients. By predicting
ingredient usage, managers can set more intelligent restock thresholds and 
ensure that ingredients are in stock and used in a timely manner so as to not
expire.

## Tech Stack

Backend: The backend will utilize Maven to build the Java project, JDBC for 
connections to the TAMU AWS PostgreSQL database, and Javalin for the web server
due to its simplicity. Depending on how we're hosting the backend, we may use
tunneling tools like Cloudflare Tunnel to expose our localhost for the web 
application to use during demonstrations.

Frontend: The frontend will utilize React for the web application and Tailwind
to handle CSS. The application will be hosted on Vercel and will use Vite for
bundling. Authentication will be performed using OAuth2.0.

Novel Feature: The novel feature will utilize Python and PyTorch to build and
train the recurrent neural network. The database will be ingested using Pandas
and the project will be managed and built using uv.
