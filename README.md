# Team 12 Project 3

This project is a web-based frontend for Panda Express that supports manager reports and a kiosk-style ordering system for customers.

## Roles

Frontend: Evan Chang
Backend: Kedar Panchal

## Novel Feature

We aim to build a machine learning model that can predict when the manager needs to restock ingredients based on the current inventory and sales data.
